# cfreyes7.github.io

Personal website of **Fabián Reyes Duarte** — Tech Lead & Software Architect.

Live at <https://cfreyes7.github.io/>.

## Structure

- `index.html` and `assets/` — the personal site (static HTML/CSS, no build step).
- `ova-unad-2016/` — archived 2016 university project: a virtual learning object (OVA) for the UNAD "Systems Design" course, kept as-is for reference.

## Local preview

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
